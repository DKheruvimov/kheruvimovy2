# Шаблон архитектуры PHP + MySQL для Wedding Invitation CMS

Этот каталог содержит полноценный, оптимизированный в соответствии со стандартами промышленной разработки бэкенд на **PHP 8.x** и **MySQL 8.0+**, спроектированный специально для вашей свадебной страницы с визуальным live-редактором (Visual CMS).

## Структура папки бэкенда
* `schema.sql`: Схема СУБД (MySQL DDL) для создания базы данных и таблиц настроек, расписания, устава и подписей гостей (RSVP).
* `config.php`: Безопасное подключение к СУБД с превентивными мерами, использующее расширение **PDO** с обработкой исключений и встроенной защитой от SQL-инъекций.
* `api.php`: Ядро REST API роутера, содержащего три транзакционных эндпоинта:
  - `get_content`: Получение текущих текстов, тем и блоков для рендеринга страницы.
  - `save_content`: Запись изменений из визуального редактора админки за одну атомарную транзакцию.
  - `rsvp`: Сохранение анкеты гостя с выбором блюд, напитков и спутников.
  - `get_rsvps`: Список всех ответов для административной панели.

## Локальное развертывание (Wordpress/Joomla style)

Для максимальной простоты размещения на любом хостинге (LAMP/MAMP/WAMP/OpenServer/cPanel), мы создали интеллектуальный **веб-установщик (Installer Wizard)**, полностью аналогичный подходу популярных CMS!

### 1. Веб-инсталляция в 1 клик (Рекомендуется):
1. Скопируйте все содержимое папки `/php-mysql` в корневую директорию вашего веб-сервера.
2. Откройте в браузере адрес веб-установщика: `http://ваш-домен/install.php`
3. Веб-интерфейс автоматически проверит совместимость вашего сервера PHP.
4. Введите реквизиты вашей базы данных MySQL. Установщик самостоятельно:
   - Создаст базу данных (если у пользователя есть соответствующие права в MySQL).
   - Выполнит импорт всех таблиц (`page_settings`, `schedule`, `estate_rules`, `rsvp_submissions`) напрямую из `schema.sql`.
   - Сгенерирует индивидуальный, защищенный `config.php` с новыми реквизитами доступа.
   - Заблокирует повторный запуск мастера установки, создав защитный файл `install.lock`.

### 2. Ручная конфигурация (Альтернатива):
1. Создайте пустую базу данных в панели phpMyAdmin.
2. Импортируйте файл схемы `schema.sql`.
3. Откройте файл `config.php` в текстовом редакторе, введите реквизиты доступа СУБД и сохраните файл на хостинг.

### 3. Размещение веб-приложения (Frontend + Backend):
* Соберите React-приложение с помощью команды `npm run build`.
* Скопируйте содержимое собранной папки `dist/` в корень вашего PHP-хостинга.
* Теперь ваше красивое интерактивное приглашение с админ-панелью будет работать на 100% автономно на вашем традиционном PHP-хостинге, сохраняя ответы гостей в базу данных MySQL и считывая динамическую конфигурацию из нее!
